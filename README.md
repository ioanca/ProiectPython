# ProiectPython

A project I made for my "Proiect Programare - Python" class during the 2nd year of engineering.

It features a local movie database with:
  User Authentication: multi-user support through a csv list
  Local storage of movie titles, genres and ratings
  Recommendations system: uses cosine similarity to compute a score and give personalized suggestions

Libraries:

  Used for mathematical functions: pandas, numpy
  
  Used for user interface: tkinter (+ ttk, messagebox, simpledialog)

It has much to be improved upon, including:

  Online search engine that lets you search for any movie in the TMDB or IMDB <br />
  Online parsed movie posters (also TMDB or IMDB) <br />
  Including more genres/categories <br />
