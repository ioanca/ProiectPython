# ProiectPython

A project I made for my "Proiect Programare - Python" class during the 2nd year of engineering. <br />

It features a local movie database with: <br />
  User Authentication: multi-user support through a csv list <br />
  Local storage of movie titles, genres and ratings <br />
  Recommendations system: uses cosine similarity to compute a score and give personalized suggestions <br />

Libraries: <br />
  Used for mathematical functions: pandas, numpy <br />
  Used for user interface: tkinter (+ ttk, messagebox, simpledialog) <br />

It has much to be improved upon, including: <br />
  Online search engine that lets you search for any movie in the TMDB or IMDB <br />
  Online parsed movie posters (also TMDB or IMDB) <br />
  Including more genres/categories <br />
