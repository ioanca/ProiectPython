# ProiectPython

A desktop application written in Python for the "Proiect Programare - Python" class during the 2nd year of engineering.

It features a local movie database with multi-user authentication, local dataset management, and a "smart" recommendation system using cosine similarity to calculate personalized movie suggestions.

## Project Overview

The Movie Recommendation System is a desktop tool created to help users organize their movie watchlists, rate movies, and discover new recommendations based on viewing history and user similarity. The application processes local dataset files (`users.csv`, `movies.csv`, `ratings.csv`) and automatically:

- Authenticates users via login and registration forms
- Tracks watched and unwatched movies per user
- Computes personalized recommendations using cosine similarity matrices
- Displays star ratings and filterable views by category
- Saves updated ratings and user details locally in CSV format

### Key Features

- **User-Friendly Interface**: Built with `tkinter` (+ `ttk`, `messagebox`, `simpledialog`) featuring a custom dark theme palette
- **Intelligent Recommendations**: Automatically calculates user-item similarity matrices using `pandas` and `numpy`
- **Category Filtering**: Allows filtering by specific movie genres and multi-category tags
- **Rating Management**: Interactive star-rating dialog for easy movie evaluations
- **Fallback Popularity Recommendation**: Automatically provides top-rated popular movies for new users with sparse data
- **Data Persistence**: Safely reads and writes user data and ratings back to `.csv` storage files

## System Requirements

- **Python**: 3.9 or higher
- **Pandas**: For tabular data manipulation and CSV handling
- **NumPy**: For linear algebra operations and cosine similarity calculations
- **Tkinter**: GUI library (included with standard Python installations)
- **CSV Data Files**: `users.csv`, `movies.csv`, and `ratings.csv`

## Usage

1. Launch the application (python main.py)
2. Log in with an existing account or register a new user profile by using non-existent credentials.
3. Navigate the main window views:
   - **TOATE** View the complete movie catalog
   - **VAZUTE** Filter movies you have already rated
   - **NEVAZUTE** View movies you haven't rated yet
   - **RECOMANDATE** View personalized recommendations generated by the system
   - **CATEGORIE** Select a specific category/genre filter from the dropdown menu
4. Double-click any row to open the interactive star-rating dialog and submit your rating

> **Note:** The application requires valid movies.csv, users.csv, and ratings.csv files present in the root directory to store state and display metadata.

## Weekend Functionality

### Overview
The recommendation engine automates the process of suggesting relevant movies to users based on collaborative filtering and matrix operations.

### How It Works

#### 1. **User-Item Matrix Construction**
- Pivots ratings.csv into a matrix where rows represent users and columns represent movies
- Replaces missing ratings with 0.0 for numerical matrix calculations

#### 2. **Cosine Similarity Computation**
- Calculates cosine similarity across all user vectors using numpy
- Identifies users with similar rating habits (similarity > 0)

#### 3. **Score Prediction Algorithm**
For each unrated movie by the current user, the system calculates a weighted predicted score

- **Weighted Rating Sum**: Multiplies ratings from similar users by their similarity score
- **Total Similarity**: Sums the similarity scores of contributing users
- **Predicted Score**: Is given as the fraction of the weighted sum and the total similarity
  
- **Popularity Fallback for New Users**:
  - If a user has no prior ratings or insufficient similar users, the system recommends top-rated popular movies based on overall mean ratings and review counts across all users
